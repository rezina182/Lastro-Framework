# Política de segurança

Para reportar uma vulnerabilidade, escreva para o contato de segurança informado abaixo. Não abra uma issue pública com os detalhes.

- Contato: seguranca@exemplo.invalid (endereço de exemplo, sem caixa real).
- Informe a versão afetada, os passos para reproduzir e o impacto que você percebeu.
- Respondemos em até 5 dias úteis e combinamos o prazo de correção antes de qualquer divulgação.
